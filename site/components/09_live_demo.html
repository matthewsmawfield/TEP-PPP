9. Live Operational Demonstration

This section is a live operational demonstration, not a manuscript figure. The dashboard below connects to a backend server that streams real-time TEP kriging predictions from a network of GNSS reference stations. The server receives raw RTCM3 streams from free public NTRIP casters (AGRS-NL in the Netherlands and ReNEP in Portugal, both accessible without registration), converts them to RINEX via RTKLIB convbin, extracts per-epoch receiver clock biases via RTKLIB SPP (rnx2rtkp -p 0 -y 2), and computes the distance-structured kriging prediction. When the casters are unreachable, the server replays archived broadcast SPP data (DOY 100, 2024) in simulation mode. The obstruction simulation drops the visible satellite count to three and compares position error with the kernel prior, a persistence prior, and no prior.

The dashboard also displays the centimetre-level PPP-AR (precise point positioning with ambiguity resolution) result from the connected USB GPS receiver, alongside the walk-forward causal Rolling-Ridge Refit (RRR) clock holdover engine operating across 68 live reference stations ($1.6$ km to $2{,}827$ km). Across the walk-forward evaluation corpus (results/outputs/live_rrr_attribution_and_position.json), the causal network predictor reduces two-hour clock holdover RMSE by $+29.30\%$ mean ($+29.48\%$ median, 90th percentile $+56.49\%$), separates from a 100-realisation station-identity permutation null at $12.78\sigma$ ($13.01\sigma$ median), retains $97.6\%$ of its station skill after global common-mode removal ($+25.83\%$ mean), and achieves $+25.14\%$ mean ($+28.53\%$ median) when restricted exclusively to stations beyond $360$ km.
